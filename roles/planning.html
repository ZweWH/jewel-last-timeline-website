THE SHARED MISSION

Roadworks and missing materials could delay the waterfall equipment delivery.

On an imagined top-down site map, the Planning Engineer arranges diversions while the Quantity Surveyor checks the parts and their supplied costs. Together they test the route and make sure the delivery is complete.

These mission ideas and maps are concepts, not proof of the real Jewel’s services or finished game features.

Work together. Each player completes a role-specific part. Once both parts are done, each earns one jigsaw piece.

    First delivery

    Issue: A closed road blocks a delivery of service fittings.

    Planning Engineer

    Place a barrier and route arrows, then test the delivery vehicle.

    Quantity Surveyor

    Count the fittings on the supplied drawing and check the delivery list.

    LEVEL MAP · CONCEPT

    Suggested setting: Imagined site entrance

    Start: Count the fittings→Issue: Set the diversion→Goal: Test delivery
  2. LEVEL 02PIECES 17 + 27 / 50 · ONE EACH

    Pipe route and cost

    Issue: The next road closure changes the route for a pipe delivery.

    Planning Engineer

    Adjust the diversion while keeping emergency access open.

    Quantity Surveyor

    Measure the pipe run on the supplied plan and price it using the given rate.

    LEVEL MAP · CONCEPT

    Suggested setting: Imagined site junction

    Start: Measure the pipe→Issue: Keep access open→Goal: Deliver the pipe
  3. LEVEL 03PIECES 18 + 28 / 50 · ONE EACH

    Two deliveries

    Issue: Two equipment deliveries must share a narrow road.

    Planning Engineer

    Set the route and choose a safe order for the two test vehicles.

    Quantity Surveyor

    Check the equipment schedule and identify any missing pump.

    LEVEL MAP · CONCEPT

    Suggested setting: Imagined narrow road

    Start: Check the schedule→Issue: Order the vehicles→Goal: Reach the work area
  4. LEVEL 04PIECES 19 + 29 / 50 · ONE EACH

    Changed work area

    Issue: A new work area changes the route and adds pipe parts.

    Planning Engineer

    Revise the diversion and protect the pedestrian crossing.

    Quantity Surveyor

    Update the part quantities and calculate the change using supplied rates.

    LEVEL MAP · CONCEPT

    Suggested setting: Imagined site crossing

    Start: Revise the route→Issue: Update quantities→Goal: Check the change
  5. LEVEL 05PIECES 20 + 30 / 50 · ONE EACH

    Compare the supplied quotes and select a complete package within budget.

    Suggested setting: Imagined pump yard

    Start: Choose the package→Issue: Test the route→Goal: Confirm delivery
